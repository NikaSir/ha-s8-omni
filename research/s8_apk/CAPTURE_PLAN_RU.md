# Безопасный захват команд S8 OMNI из Smart Life

Дата: 2026-09-04

## Цель

Получить фактические исходящие DP-команды штатной панели S8 OMNI без записи в неизвестные DP со стороны Home Assistant.

Используем Frida только как **пассивный перехватчик** вызовов `publishDps` / `publishCommands`. Скрипт не меняет значения аргументов, не добавляет вызовы и не имеет собственного сетевого транспорта.

## Подготовка

Нужен Android-телефон/эмулятор, на котором можно подключить Frida Server или Frida Gadget.

Проверить приложение:

```bash
frida-ps -Uai | grep -i -E 'smart.?life|tuya'
```

Запуск под перехватом:

```bash
frida -U -f com.tuya.smartlife \
  -l research/s8_apk/frida_smartlife_publish_dps.js \
  -o s8_publish_dps.log
```

Либо подключиться к уже открытому процессу:

```bash
frida -U -n 'Smart Life' \
  -l research/s8_apk/frida_smartlife_publish_dps.js \
  -o s8_publish_dps.log
```

После появления строки:

```text
[S8_DP_PROBE] installed
```

открыть панель S8 и выполнять **одно действие за раз**.

## Порядок тестов

### A. Верификация самого перехвата

Робот должен стоять на базе.

1. В штатном приложении запустить сушку.
2. Подождать 3–5 секунд.
3. Остановить сушку.

Ожидаем уже подтверждённые для S8 переходы:

```text
DP136 = true
DP136 = false
```

Если эти две записи не видны — к неизвестным функциям не переходить. Сначала исправить захват.

### B. Безопасные простые функции

После успешного A:

1. `Seek Robot` / «Найти робот» — один вызов.
2. DND — сдвинуть время на одну минуту, сохранить, затем вернуть исходное.
3. Ручное управление — открыть экран, кратко нажать одно направление, отпустить, выйти.

Цель — определить точные DP code/id и порядок записей.

### C. Выбранная комната

1. Робот в покое.
2. Выбрать ровно одну комнату.
3. Запустить уборку.
4. После появления фактического движения остановить штатной кнопкой Pause/Stop.

Нужны события вокруг старта:

```text
command_trans ?
mode = select_room ?
switch_go = true ?
```

Важны не только значения, но и **порядок вызовов**.

### D. Зона и точка

Повторить по одному контролируемому примеру:

- одна прямоугольная зона;
- одна точка «Куда убрать».

Не менять виртуальные стены и карту на этом этапе.

## Не выполнять до декодирования

- удалить карту;
- сбросить карту;
- разделить/объединить комнаты;
- писать виртуальные стены;
- писать запретные зоны;
- писать DP145;
- вручную отправлять кадры из BSTY/Amicro/Philips или generic Tuya reference.

## Что сохранить после каждого действия

Для каждого теста сохранить:

1. время действия;
2. название действия;
3. фрагмент `s8_publish_dps.log`;
4. фактическое состояние робота после команды;
5. при наличии — снимок Home Assistant diagnostics до/после.

Полные Device ID, Local Key, токены и данные аккаунта не публиковать.

## Критерий `S8_VERIFIED`

Новая команда допускается в рабочую интеграцию только когда одновременно есть:

1. точный numeric DP + exact code из S8-схемы;
2. пассивный захват этой команды из штатной панели;
3. валидная длина/checksum бинарного кадра, если он используется;
4. контролируемое локальное воспроизведение;
5. физически правильная реакция S8;
6. readback/status, подтверждающий результат;
7. безопасная остановка штатной Pause/Home.
